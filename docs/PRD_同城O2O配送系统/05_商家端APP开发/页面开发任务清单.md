# 商家端APP页面开发任务清单

> 本文档包含商家端APP全部20个页面的详细开发规格。  
> 技术栈：uni-app x (Vue3 + UTS)，编译目标：安卓+iOS双端APP。

---

## 全局约定

### 统一响应格式

所有后端接口返回：`{ code, message, data }`。成功码为`0`，错误码按服务域分段定义（详见阶段03《接口规范与状态机》错误码表），如`11001`未登录，`11003`无权限，`10002`不存在，`10001`参数错误，`10005`服务器错误。

### 金额与时间

- 金额以**分**为单位（整数），展示时除以100保留2位小数
- 时间使用ISO 8601字符串或毫秒时间戳

### 商家端特殊约定

- 商家端需常驻后台运行，保证新订单消息及时接收
- 新订单必须有语音播报+震动+弹窗提醒
- 接单操作必须在限定时间内完成，超时系统自动处理
- 关键操作（接单/拒单/售后处理）需要二次确认

## MC-01 注册登录页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | MC-01 |
| 页面名称 | 注册登录页 |
| 路由 | pages/auth/login |
| 页面目标 | 商家通过手机号+验证码或密码完成登录/注册 |

### 入口与出口

- **入口**：APP启动（未登录时）
- **出口**：登录成功 → 已入驻跳转MC-05工作台，未入驻跳转MC-02入驻申请

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 品牌Logo + "商家版" |
| 登录方式Tab | 验证码登录 / 密码登录 |
| 表单区 | 手机号输入 + 验证码/密码输入 |
| 操作区 | "登录"按钮 + "忘记密码" |
| 底部 | 用户协议 + 隐私政策勾选 |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| loginType | string | 用户操作 | sms/password |
| phone | string | 用户输入 | 手机号 |
| smsCode | string | 用户输入 | 短信验证码 |
| password | string | 用户输入 | 密码 |
| agreed | boolean | 用户操作 | 是否同意协议 |

### 用户操作与交互逻辑

1. 切换验证码/密码登录Tab
2. 输入手机号，点击"获取验证码"（60秒倒计时）
3. 输入验证码/密码，点击"登录"
4. 登录成功：
   - 已入驻且已审核通过 → 跳转MC-05工作台
   - 已入驻审核中 → 跳转MC-03审核进度
   - 未入驻 → 跳转MC-02入驻申请
5. 注册推送设备Token（登录成功后自动执行）

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 发送验证码 | POST | /api/merchant/auth/sms-code | `{ phone }` |
| 商家登录 | POST | /api/merchant/auth/login | `{ phone, smsCode?, password?, loginType }` |

### 校验规则

| 字段 | 规则 |
|------|------|
| 手机号 | 必填，`/^1[3-9]\d{9}$/` |
| 验证码 | 必填（验证码登录时），6位数字 |
| 密码 | 必填（密码登录时），6-20位 |
| 协议勾选 | 必须勾选 |

### 验收要点

- [ ] 验证码登录流程完整
- [ ] 密码登录流程完整
- [ ] 验证码60秒倒计时
- [ ] 登录后根据入驻状态跳转
- [ ] 协议未勾选时禁止登录

## MC-06 新订单弹窗/播报

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | MC-06 |
| 页面名称 | 新订单弹窗/播报 |
| 路由 | 全局组件（非独立页面） |
| 页面目标 | 新订单到达时弹窗提醒+语音播报+震动，支持快速接单/拒单 |

### 触发条件

- 收到推送消息（极光推送）且消息类型为新订单
- APP在前台 → 弹窗+语音+震动
- APP在后台 → 推送通知+语音播报（锁屏也可播报）

### 弹窗布局

| 区域 | 内容 |
|------|------|
| 弹窗顶部 | "新订单" + 订单类型标签（商品/跑腿） |
| 订单摘要 | 商品列表摘要 / 跑腿服务描述 |
| 金额 | 订单金额 |
| 倒计时 | 接单倒计时（默认5分钟，从后台配置读取） |
| 操作按钮 | "接单" + "拒单" |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| orderId | string | 推送数据 | 订单ID |
| orderType | string | 推送数据 | product/errand |
| orderSummary | string | 推送数据 | 订单摘要 |
| amount | number | 推送数据 | 金额（分） |
| countdown | number | 推送数据/配置 | 接单倒计时（秒） |

### 用户操作与交互逻辑

1. 新订单推送到达 → 播报语音"您有新的订单，请及时处理" → 展示弹窗
2. 语音播报循环3次（可在设置中关闭）
3. 手机震动提醒
4. 点击"接单" → 调用接单接口 → 成功后弹窗关闭，Toast"接单成功"
5. 点击"拒单" → 弹出拒单原因选择 → 确认后调用拒单接口
6. 倒计时结束 → 弹窗自动关闭（后端会自动处理超时）
7. 多个订单同时到达 → 排队展示（处理完一个再展示下一个）

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 接单 | POST | /api/merchant/order/:id/accept | 无 |
| 拒单 | POST | /api/merchant/order/:id/reject | `{ reason }` |

### 验收要点

- [ ] 新订单推送触发弹窗
- [ ] 语音播报正常（前台+后台+锁屏）
- [ ] 震动提醒正常
- [ ] 接单操作成功
- [ ] 拒单需选择原因
- [ ] 倒计时显示和到期处理正常
