## 一、蓝牙打印对接方案

### 1.1 整体方案

商家接单后需自动或手动打印订单小票，通过蓝牙连接热敏打印机，发送ESC/POS指令进行打印。

### 1.2 技术实现

#### 打印机发现与连接

```
流程：开启蓝牙适配器 → 搜索附近设备 → 用户选择打印机 → 建立连接 → 保存设备信息
```

**uni-app x API调用链路：**

1. `uni.openBluetoothAdapter()` — 初始化蓝牙模块
2. `uni.startBluetoothDevicesDiscovery({ services: [] })` — 开始搜索
3. `uni.onBluetoothDeviceFound(callback)` — 监听发现设备
4. `uni.stopBluetoothDevicesDiscovery()` — 停止搜索
5. `uni.createBLEConnection({ deviceId })` — 连接设备
6. `uni.getBLEDeviceServices({ deviceId })` — 获取服务
7. `uni.getBLEDeviceCharacteristics({ deviceId, serviceId })` — 获取特征值
8. `uni.writeBLECharacteristicValue(...)` — 写入打印数据

#### 打印机类型适配

| 连接方式 | 适用打印机 | uni-app x支持 |
|----------|------------|------------|
| BLE (低功耗蓝牙) | 佳博、商米便携打印机 | uni.createBLEConnection |
| 经典蓝牙(SPP) | 传统蓝牙打印机 | 需原生插件支持 |

优先适配BLE方式，覆盖主流打印机品牌。

#### ESC/POS打印指令

```typescript
// services/printerService.uts

class PrinterService {
  private deviceId: string = '';
  private serviceId: string = '';
  private characteristicId: string = '';

  // 初始化打印机
  async init(): Promise<void> {
    await uni.openBluetoothAdapter({});
  }

  // 搜索打印机
  async discover(): Promise<BluetoothDevice[]> {
    return new Promise((resolve) => {
      const devices: BluetoothDevice[] = [];
      uni.startBluetoothDevicesDiscovery({ services: [] });
      uni.onBluetoothDeviceFound((res) => {
        res.devices.forEach(d => {
          if (d.name && d.name.length > 0) {
            devices.push(d);
          }
        });
      });
      setTimeout(() => {
        uni.stopBluetoothDevicesDiscovery({});
        resolve(devices);
      }, 5000);
    });
  }

  // 连接打印机
  async connect(deviceId: string): Promise<void> {
    this.deviceId = deviceId;
    await uni.createBLEConnection({ deviceId });
    // 获取打印服务和特征值...
  }

  // 打印订单
  async printOrder(order: OrderData): Promise<void> {
    const commands = this.buildOrderCommands(order);
    await this.sendData(commands);
  }

  // 构建ESC/POS指令
  private buildOrderCommands(order: OrderData): Uint8Array {
    const encoder = new EscPosEncoder();
    encoder
      .initialize()
      .align('center')
      .bold(true)
      .text(order.shopName)
      .bold(false)
      .newline()
      .text('--------------------')
      .newline()
      .align('left')
      .text(`订单号: ${order.orderNo}`)
      .newline()
      .text(`下单时间: ${order.createdAt}`)
      .newline()
      .text('--------------------')
      .newline();

    // 商品列表
    order.products.forEach(p => {
      encoder
        .text(`${p.name}`)
        .text(`  x${p.quantity}  ¥${(p.price * p.quantity / 100).toFixed(2)}`)
        .newline();
    });

    encoder
      .text('--------------------')
      .newline()
      .text(`合计: ¥${(order.payAmount / 100).toFixed(2)}`)
      .newline()
      .text(`备注: ${order.remark || '无'}`)
      .newline()
      .text(`收货人: ${order.address.name} ${order.address.phone}`)
      .newline()
      .text(`地址: ${order.address.address}`)
      .newline()
      .cut();

    return encoder.encode();
  }

  // 分包发送数据（蓝牙MTU限制，每包20字节）
  private async sendData(data: Uint8Array): Promise<void> {
    const chunkSize = 20;
    for (let i = 0; i < data.length; i += chunkSize) {
      const chunk = data.slice(i, i + chunkSize);
      await uni.writeBLECharacteristicValue({
        deviceId: this.deviceId,
        serviceId: this.serviceId,
        characteristicId: this.characteristicId,
        value: chunk.buffer,
      });
      await this.delay(20); // 防止发送过快
    }
  }

  private delay(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}
```

### 1.3 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 蓝牙未开启 | 弹窗引导用户开启蓝牙 |
| 打印机未找到 | 提示"未发现打印机，请确认打印机已开启" |
| 连接断开 | 自动尝试重连（最多3次），失败后提示重新搜索 |
| 打印超时 | 超时10秒后提示"打印超时，请检查打印机状态" |
| 纸张用尽 | 提示"请检查打印纸" |
| 数据发送失败 | 重试发送，3次失败后提示 |

### 1.4 安卓与iOS差异

| 差异点 | 安卓 | iOS |
|--------|------|-----|
| 蓝牙权限 | 需要BLUETOOTH、BLUETOOTH_ADMIN、LOCATION权限 | 需要蓝牙使用描述 |
| BLE MTU | 默认20字节，可协商至更大 | 默认20字节 |
| 经典蓝牙 | 支持SPP串口通信 | 不支持（需走BLE或MFi） |
| 后台蓝牙 | 支持后台蓝牙操作 | 需声明Background Mode |

## 二、离线推送方案

### 2.1 整体方案

使用**极光推送(JPush)**统一管理安卓和iOS的离线消息推送，实现新订单、售后通知、系统消息的及时触达。

### 2.2 集成步骤

#### uni-app x插件集成

使用极光推送uni-app x官方插件 `JG-JPush`：

```json
// manifest.json 中配置
{
  "app-plus": {
    "plugins": {
      "jpush": {
        "appkey_android": "YOUR_JPUSH_APPKEY",
        "appkey_ios": "YOUR_JPUSH_APPKEY",
        "channel": "merchant"
      }
    }
  }
}
```

#### 初始化与注册

```typescript
// services/pushService.uts

class PushService {
  // APP启动时初始化
  init(): void {
    const jpush = uni.requireNativePlugin('JG-JPush');

    // 初始化
    jpush.initJPush();

    // 获取RegistrationID
    jpush.getRegistrationID((result: { registerID: string }) => {
      if (result.registerID) {
        this.reportToken(result.registerID);
      }
    });

    // 监听通知点击
    jpush.addNotificationListener((result: any) => {
      this.handleNotificationClick(result);
    });

    // 监听自定义消息（透传消息）
    jpush.addCustomMessageListener((result: any) => {
      this.handleCustomMessage(result);
    });
  }

  // 上报推送Token到后端
  private async reportToken(token: string): Promise<void> {
    await api.post('/api/merchant/push/register', {
      token,
      platform: uni.getSystemInfoSync().platform, // android/ios
      deviceId: uni.getSystemInfoSync().deviceId,
    });
  }

  // 处理通知点击
  private handleNotificationClick(data: any): void {
    const { type, orderId } = data.extras;
    switch (type) {
      case 'new_order':
        uni.navigateTo({ url: `/pages/order/detail?id=${orderId}` });
        break;
      case 'aftersale':
        uni.navigateTo({ url: '/pages/order/aftersale' });
        break;
      default:
        uni.navigateTo({ url: '/pages/message/index' });
    }
  }

  // 处理透传消息（APP在前台时）
  private handleCustomMessage(data: any): void {
    const { type } = data;
    if (type === 'new_order') {
      // 触发新订单弹窗
      uni.$emit('newOrderArrived', data);
    }
  }
}
```

## 三、语音播报方案

### 3.1 整体方案

新订单到达时通过TTS（Text-To-Speech）引擎合成语音进行播报，支持前台、后台和锁屏状态播报。

### 3.2 技术实现

```typescript
// services/voiceService.uts

class VoiceService {
  private audioContext: any = null;
  private isPlaying: boolean = false;
  private playCount: number = 0;
  private maxPlayCount: number = 3; // 最多播放3次
  private enabled: boolean = true;

  // 使用系统TTS引擎播报
  speak(text: string): void {
    if (!this.enabled) return;

    // #ifdef APP-PLUS
    const speech = plus.audio.createPlayer('');

    // 安卓使用原生TTS
    if (uni.getSystemInfoSync().platform === 'android') {
      this.speakAndroid(text);
    } else {
      // iOS使用AVSpeechSynthesizer
      this.speakIOS(text);
    }
    // #endif
  }

  // 安卓TTS播报
  private speakAndroid(text: string): void {
    const tts = uni.requireNativePlugin('TTS-Engine');
    tts.speak({
      text: text,
      language: 'zh-CN',
      rate: 1.0,
      pitch: 1.0,
      onDone: () => {
        this.playCount++;
        if (this.playCount < this.maxPlayCount) {
          setTimeout(() => this.speakAndroid(text), 1000);
        } else {
          this.playCount = 0;
        }
      }
    });
  }

  // iOS TTS播报
  private speakIOS(text: string): void {
    const tts = uni.requireNativePlugin('TTS-Engine');
    tts.speak({
      text: text,
      language: 'zh-CN',
      rate: 0.5,
      onDone: () => {
        this.playCount++;
        if (this.playCount < this.maxPlayCount) {
          setTimeout(() => this.speakIOS(text), 1000);
        } else {
          this.playCount = 0;
        }
      }
    });
  }

  // 备选方案：使用音频文件播报
  playAudio(url: string): void {
    this.audioContext = uni.createInnerAudioContext();
    this.audioContext.src = url;
    this.audioContext.play();
  }

  // 停止播报
  stop(): void {
    this.isPlaying = false;
    this.playCount = 0;
    if (this.audioContext) {
      this.audioContext.stop();
    }
  }

  // 开关控制
  setEnabled(enabled: boolean): void {
    this.enabled = enabled;
  }
}
```

## 四、后台保活方案

### 4.1 整体方案

商家端APP需要常驻后台运行，保证推送消息和订单提醒及时接收。

### 4.2 安卓方案

```typescript
// nativeplugins/keep-alive/android

// 方案1: 前台Service（推荐）
// 在通知栏展示常驻通知"商家版正在运行中"
class ForegroundService {
  start(): void {
    const keepAlive = uni.requireNativePlugin('Keep-Alive');
    keepAlive.startForegroundService({
      title: '商家版',
      content: '正在运行中，保证订单及时接收',
      icon: 'notification_icon'
    });
  }

  stop(): void {
    const keepAlive = uni.requireNativePlugin('Keep-Alive');
    keepAlive.stopForegroundService();
  }
}

// 方案2: WorkManager定时唤醒
// 每5分钟检查一次APP状态，如果被杀死则拉起
```

### 4.3 iOS方案

```
iOS后台保活策略：
1. Background Modes → Audio: 播放静音音频保活（审核风险较高）
2. Background Modes → Remote notifications: APNs静默推送唤醒
3. Background Modes → Background fetch: 定期后台刷新
4. VoIP推送（如适用）：高优先级推送，可唤醒APP

推荐方案: Remote notifications + Background fetch 组合
```

### 4.4 保活优先级策略

| 优先级 | 安卓 | iOS |
|--------|------|-----|
| 最高 | 前台Service + 通知栏 | APNs远程推送 |
| 高 | WorkManager定时任务 | Background fetch |
| 中 | AlarmManager | 静默推送唤醒 |
| 低 | 双进程守护（不推荐） | 后台音频（审核风险） |

### 4.5 厂商自启动引导

安卓各厂商对后台应用有不同的限制策略，需要引导用户设置：

| 厂商 | 设置路径 | 引导方式 |
|------|----------|----------|
| 华为 | 设置 → 应用 → 启动管理 → 允许自启动和后台运行 | 首次启动弹窗引导 |
| 小米 | 设置 → 应用管理 → 权限 → 自启动 | 首次启动弹窗引导 |
| OPPO | 设置 → 电池 → 应用耗电管理 → 允许后台运行 | 首次启动弹窗引导 |
| vivo | 设置 → 电池 → 后台高耗电 → 允许 | 首次启动弹窗引导 |
| 三星 | 设置 → 电池 → 未监视的应用 → 添加 | 首次启动弹窗引导 |

## 五、离线缓存方案

### 5.1 整体方案

商家在断网环境下，仍可查看已接单订单的基本信息，网络恢复后自动同步。

### 5.2 缓存策略

| 数据类型 | 缓存方式 | 缓存时效 | 同步策略 |
|----------|----------|----------|----------|
| 已接单订单列表 | SQLite本地库 | 24小时 | 网络恢复后自动拉取最新数据覆盖 |
| 订单详情 | SQLite本地库 | 查看过的订单缓存 | 网络恢复后更新 |
| 商品列表 | SQLite本地库 | 4小时 | 启动时和定时刷新 |
| 打印机配置 | Storage | 永久 | 仅本地配置 |
| 用户设置 | Storage | 永久 | 登录时同步 |

### 5.3 技术实现

```typescript
// services/offlineService.uts

class OfflineService {
  private db: any = null;

  // 初始化SQLite
  async init(): Promise<void> {
    // #ifdef APP-PLUS
    this.db = plus.sqlite.openDatabase({
      name: 'merchant_cache',
      path: '_doc/merchant.db'
    });

    // 创建缓存表
    await this.execSQL(`
      CREATE TABLE IF NOT EXISTS order_cache (
        id TEXT PRIMARY KEY,
        data TEXT NOT NULL,
        updated_at INTEGER NOT NULL
      )
    `);

    await this.execSQL(`
      CREATE TABLE IF NOT EXISTS product_cache (
        id TEXT PRIMARY KEY,
        data TEXT NOT NULL,
        updated_at INTEGER NOT NULL
      )
    `);
    // #endif
  }

  // 缓存订单数据
  async cacheOrders(orders: any[]): Promise<void> {
    const now = Date.now();
    for (const order of orders) {
      await this.execSQL(
        `INSERT OR REPLACE INTO order_cache (id, data, updated_at) VALUES (?, ?, ?)`,
        [order.id, JSON.stringify(order), now]
      );
    }
  }

  // 读取缓存订单
  async getCachedOrders(): Promise<any[]> {
    const cutoff = Date.now() - 24 * 60 * 60 * 1000; // 24小时前
    const result = await this.selectSQL(
      'SELECT data FROM order_cache WHERE updated_at > ? ORDER BY updated_at DESC',
      [cutoff]
    );
    return result.map((r: any) => JSON.parse(r.data));
  }

  // 网络状态监听
  startNetworkMonitor(): void {
    uni.onNetworkStatusChange((res) => {
      if (res.isConnected) {
        this.syncData();
      }
    });
  }

  // 网络恢复后同步
  private async syncData(): Promise<void> {
    try {
      // 拉取最新订单列表覆盖缓存
      const orders = await api.get('/api/merchant/order/list', {
        status: 'active',
        pageSize: 50
      });
      await this.cacheOrders(orders.data.list);
      uni.showToast({ title: '数据已同步', icon: 'success' });
    } catch (e) {
      // 静默失败，等待下次同步
    }
  }

  }
```

### 5.4 数据一致性保证

- 本地缓存仅用于**只读展示**，不支持离线状态下修改数据
- 网络恢复后以服务端数据为准，覆盖本地缓存
- 使用 `updated_at` 时间戳做数据过期清理
- 接单、拒单等写操作必须在线执行，离线时提示用户
