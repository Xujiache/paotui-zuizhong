# 阶段07：平台管理后台开发

> 版本: v1.0
> 状态: 基线版
> 前置依赖: 阶段03后端核心业务服务可用、阶段01技术架构与项目规范已确认

---

## 一、阶段目标

完成平台管理后台（PC端）全部24个菜单页面的开发，实现平台对用户、商家、骑手、订单、商品、区域、计价、结算、营销、消息、风控、权限和审计的全面管控能力。

具体目标：
1. 基于 art-design-pro 模板，使用 Vue 3.5 + Vite 7 + Element Plus 2.11 + Tailwind CSS 4 + Pinia 3 + TypeScript 5.6 开发24个菜单页面
2. 实现完整的RBAC权限体系（菜单权限 + 数据权限 + 操作权限）
3. 覆盖5个平台角色（超级管理员、运营人员、审核人员、客服人员、财务人员）的差异化访问控制
4. 所有列表页支持搜索、分页、排序、导出
5. 所有表单支持校验、提交、反馈
6. 关键操作记录审计日志

## 十二、风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| 后端接口不稳定导致前端联调受阻 | 中 | 高 | 使用Mock数据先行开发，接口稳定后切换 |
| 地图组件在IE/低版本浏览器不兼容 | 低 | 中 | 明确最低浏览器版本要求（Chrome 90+） |
| 权限体系设计变更 | 低 | 高 | 权限矩阵冻结后再开发，变更走偏差控制 |
| 24个页面开发量大超出工期 | 中 | 高 | 抽取公共组件复用，按优先级分批交付 |
| ECharts/地图组件包体积过大 | 中 | 中 | 使用按需引入和代码分割 |
