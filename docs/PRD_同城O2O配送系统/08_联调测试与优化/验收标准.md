## 一、核心流程验收清单

### 1.1 商品订单端到端流程

| 序号 | 验收项 | 操作步骤 | 通过标准 | 状态 |
|------|--------|----------|----------|------|
| 1 | 用户浏览商家 | 小程序首页→选择分类→查看商家列表 | 商家列表正确加载，展示距离、配送费、起送价 | [ ] |
| 2 | 用户加购下单 | 选商品→加购物车→确认订单→选地址→选优惠券 | 购物车金额正确，配送费正确，优惠券抵扣正确 | [ ] |
| 3 | 用户支付 | 确认订单→微信支付 | 支付成功，订单状态变为待商家接单 | [ ] |
| 4 | 商家收到通知 | 商家APP自动弹窗/语音播报 | 商家端收到新订单提醒 | [ ] |
| 5 | 商家接单 | 商家APP点击接单 | 订单状态变为待骑手接单，用户收到通知 | [ ] |
| 6 | 骑手收到推送 | 骑手APP订单池显示新订单 | 骑手能看到订单信息、取货地址、送达地址 | [ ] |
| 7 | 骑手抢单 | 骑手点击抢单→确认 | 订单绑定骑手，其他骑手不可再抢 | [ ] |
| 8 | 骑手取货 | 骑手到店→扫码核验→确认取货 | 状态变为配送中，用户端开始显示骑手位置 | [ ] |
| 9 | 配送中追踪 | 用户小程序查看订单详情 | 地图显示骑手实时位置和预计送达时间 | [ ] |
| 10 | 骑手送达 | 骑手确认送达→拍照 | 状态变为已送达，用户收到送达通知 | [ ] |
| 11 | 用户确认收货 | 用户点击确认收货 | 订单完成，触发结算 | [ ] |
| 12 | 用户评价 | 用户提交评分和评价内容 | 评价保存成功 | [ ] |

### 1.2 跑腿订单端到端流程（帮送）

| 序号 | 验收项 | 操作步骤 | 通过标准 | 状态 |
|------|--------|----------|----------|------|
| 1 | 选择帮送服务 | 小程序首页→跑腿频道→帮送 | 帮送表单页正确展示 | [ ] |

| 3 | 费用预估 | 提交后查看预估费用 | 展示基础费+距离费+重量费等明细 | [ ] |
| 4 | 用户支付 | 确认发单→微信支付 | 支付成功，订单进入待接单 | [ ] |
| 5 | 骑手抢单 | 骑手APP订单池→抢单 | 订单绑定骑手 | [ ] |
| 6 | 骑手前往取件 | 骑手出发→导航到取件地址 | 状态变为前往取件 | [ ] |
| 7 | 骑手取件并配送 | 确认取件→配送到收件地址 | 状态流转正确 | [ ] |
| 8 | 骑手送达确认 | 确认送达 | 状态变为已送达 | [ ] |
| 9 | 用户确认完成 | 用户确认收到 | 订单完成，触发结算 | [ ] |

### 1.4 售后退款端到端流程

| 序号 | 验收项 | 操作步骤 | 通过标准 | 状态 |
|------|--------|----------|----------|------|
| 1 | 用户申请退款 | 小程序订单详情→申请退款→填写原因 | 售后单创建成功 | [ ] |
| 2 | 后台受理 | 管理后台售后中心→受理 | 状态变为处理中 | [ ] |

| 5 | 结算回滚 | 退款后检查结算 | 关联结算单状态正确更新 | [ ] |

## 五、上线前检查清单

### 5.1 功能完整性检查

- [ ] 商品订单完整主流程测试通过（下单→支付→接单→配送→收货→结算）
- [ ] 跑腿订单完整主流程测试通过（帮送/帮取/帮买/代办各一轮）
- [ ] 商家拒单/超时自动退款流程测试通过
- [ ] 用户取消/退款流程测试通过
- [ ] 骑手异常上报流程测试通过
- [ ] 结算/提现流程测试通过
- [ ] 管理后台24个菜单功能全部可用
- [ ] 5个后台角色权限边界全部验证通过

### 5.2 数据一致性检查

- [ ] 订单状态在各终端展示一致（用户端/商家端/骑手端/后台）
- [ ] 支付金额与订单金额一致
- [ ] 结算金额拆分正确（商家+骑手+平台=订单实付）
- [ ] 退款金额不超过实付金额
- [ ] 优惠券使用后标记为已使用，不可重复使用
- [ ] 库存变更正确（下单扣减、取消恢复）

### 5.3 安全检查

- [ ] 所有接口均需Token认证（登录/注册除外）
- [ ] 支付回调验签正确
- [ ] 敏感数据加密存储（密码、密钥）
- [ ] 前端敏感信息脱敏（手机号、身份证）
- [ ] SQL注入防护（参数化查询）
- [ ] XSS防护（输出转义）
- [ ] 接口限流配置生效
- [ ] HTTPS证书有效

### 5.4 日志与监控检查

- [ ] 核心接口有请求/响应日志
- [ ] 支付回调有完整日志
- [ ] 状态流转有操作日志
- [ ] 后台敏感操作有审计日志
- [ ] 异常堆栈有错误日志
- [ ] 日志级别配置正确（生产环境不输出DEBUG日志）

### 5.5 配置检查

- [ ] 数据库连接池配置合理
- [ ] Redis连接池配置合理
- [ ] 支付超时时间配置正确
- [ ] 商家接单超时时间配置正确
- [ ] 自动确认收货时间配置正确
- [ ] 消息推送配置正确
- [ ] 定时任务配置正确（结算、自动确认、超时关闭）
