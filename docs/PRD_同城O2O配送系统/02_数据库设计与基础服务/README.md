# 阶段02：数据库设计与基础服务

> 版本: v1.0
> 状态: 基线版
> 前置依赖: 阶段01全部验收通过

---

## 一、阶段目标

完成全部数据库表结构设计和建表，开发网关、认证授权、通用中间件等基础服务，使后续所有业务服务有可用的数据底座和基础设施。

具体目标：
1. 设计并创建30张核心业务数据表（含索引和约束）
2. 搭建统一API网关（路由分发、中间件链、日志、限流、错误处理）
3. 开发认证授权服务（微信登录、手机号登录、Token管理、RBAC权限）
4. 开发通用中间件（鉴权、参数校验、分页、响应格式化）
5. 封装Redis缓存工具（Token存储、验证码、配置缓存）
6. 开发文件上传服务和短信验证码服务

## 五、本阶段范围边界

### 做什么

- 全部数据库表结构设计和建表
- 统一网关搭建
- 认证授权完整服务
- 4种角色的登录注册流程
- 通用中间件开发
- Redis缓存工具封装
- 文件上传和短信验证码基础服务

### 不做什么

| 不做的事项 | 原因 |
|-----------|------|
| 不开发业务接口 | 用户/商家/骑手/商品/订单等业务CRUD在阶段03 |
| 不开发前端页面 | 前端在阶段04-07 |
| 不对接微信支付 | 支付对接在阶段03订单中心 |
| 不开发调度逻辑 | 调度中心在阶段03 |
| 不做种子数据填充 | 先完成表结构，测试数据后续补充 |
