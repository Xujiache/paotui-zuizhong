# 阶段03：后端核心业务服务开发

> 版本: v1.0
> 状态: 基线版
> 前置依赖: 阶段02全部验收通过

---

## 一、阶段目标

在阶段02搭建的网关、认证、数据库基础之上，完成全部11个核心业务服务域的接口开发，形成完整的后端业务能力，支撑后续前端各终端的开发。

具体目标：
1. 完成用户中心、商家中心、骑手中心的主体管理接口
2. 完成商品中心的分类、商品、SKU、库存管理接口
3. 完成订单中心的商品订单和跑腿订单全流程接口
4. 完成计价中心的费用计算引擎
5. 完成调度中心的订单池和抢单逻辑
6. 完成售后中心的退款和投诉流程
7. 完成结算中心的结算和提现流程
8. 完成消息中心的多通道消息发送
9. 完成配置中心的全局配置管理
