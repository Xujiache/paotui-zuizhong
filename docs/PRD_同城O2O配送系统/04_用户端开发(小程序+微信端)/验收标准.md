| 序号 | 异常场景 | 检查项 | 通过标准 |
|------|----------|--------|----------|
| 1 | 网络断开 | 所有页面 | 展示网络异常提示，不白屏 |
| 2 | 接口超时 | 所有接口调用 | 超时后提示，可重试 |
| 3 | Token过期 | 请求时Token失效 | 自动刷新Token或引导重新登录 |
| 4 | 数据为空 | 列表页无数据 | 展示对应空状态图 |
| 5 | 商家已关闭 | 进入已关闭商家 | 提示不可下单 |
| 6 | 商品无库存 | 下单时库存为0 | 提示库存不足 |
| 7 | 支付失败 | 微信支付失败 | 可重新支付 |
| 8 | 地址超出范围 | 下单时地址超出 | 提示超出配送范围 |
| 9 | 优惠券过期 | 使用已过期券 | 提示已过期并移除 |
| 10 | 并发加购 | 快速连续加购 | 数量正确，不重复 |
| 11 | 返回键处理 | 各页面物理返回 | 正确返回上一页，不出现异常 |
| 12 | 页面栈溢出 | 深层级跳转 | 使用redirectTo避免栈溢出 |

## 六、性能验收

| 指标 | 标准 | 测试方式 |
|------|------|----------|
| 首屏加载时间 | 首页 < 2秒 | 性能面板测量 |
| 页面切换 | < 500ms | 体感流畅 |
| 列表滚动 | 60fps无卡顿 | 体感流畅 |
| 图片加载 | 渐进式加载 | 先展示占位图 |
| 包体积 | 主包 < 2MB，总包 < 16MB | 编译后检查 |
| 内存占用 | 无内存泄漏 | 长时间使用后检查 |

## 七、安全验收

| 序号 | 检查项 | 通过标准 |
|------|--------|----------|
| 1 | Token安全存储 | 存储在Storage中，不在URL暴露 |
| 2 | 接口鉴权 | 所有敏感接口携带Token |
| 3 | 手机号脱敏 | 展示时中间4位用*号 |
| 4 | 支付安全 | 金额以服务端为准，前端不可篡改 |
| 5 | XSS防护 | 用户输入内容不直接渲染HTML |
| 6 | 敏感信息 | API Key等不在前端代码中硬编码 |
