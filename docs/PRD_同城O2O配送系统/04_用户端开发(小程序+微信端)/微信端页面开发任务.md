# 用户微信端页面开发任务

> 本文档包含用户微信端全部6个页面的详细开发规格。  
> 微信端定位为微信生态**轻量入口**，很多操作需跳转到小程序完成。  
> 开发框架：微信原生开发框架（WXML + WXSS + JS/TS）。

---

## 全局约定

### 微信端与小程序的关系

- 微信端是**轻量入口**，不重复承载完整交易主链路
- 核心交易操作（下单、支付、售后）均通过跳转小程序完成
- 微信端承接活动推广、消息通知、快捷查询等场景
- 跳转小程序使用 `wx.navigateToMiniProgram` API

### 跳转小程序工具函数

```javascript
// utils/navigate.js
function navigateToMiniApp(path, extraData = {}) {
  wx.navigateToMiniProgram({
    appId: 'wx_mini_app_id',  // 小程序AppID，从配置读取
    path: path,
    extraData: extraData,
    success: () => {},
    fail: (err) => {
      wx.showToast({ title: '跳转失败，请重试', icon: 'none' });
    }
  });
}
```

### 统一鉴权

- 微信端和小程序共享用户体系（通过UnionID关联）
- 微信端登录后获取的Token可用于调用后端接口
- Token存储在 `wx.setStorageSync('token', value)`

### 统一响应格式

同小程序端，后端接口返回 `{ code, message, data }`。

## WX-01 启动/活动承接页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | WX-01 |
| 页面名称 | 启动/活动承接页 |
| 路由 | pages/launch/index |
| 页面目标 | 承接外部分享链接、活动推广、拉新入口，根据来源类型解析参数后分发到对应页面或跳转小程序 |

### 入口与出口

- **入口**：
  - 微信聊天中点击分享卡片
  - 朋友圈活动链接
  - 公众号文章/菜单推广链接
  - 扫描活动二维码
- **出口**：
  - 跳转到WX-03快捷入口页（默认）
  - 跳转到小程序指定页面（活动、商家详情等）
  - 跳转到WX-02微信授权页（未登录时）

### 页面布局

| 区域 | 内容 |
|------|------|
| 全屏 | 活动承接页根据场景展示不同内容 |
| 场景A：活动承接 | 活动Banner图 + 活动标题 + "立即参与"按钮 |
| 场景B：分享承接 | 商家/商品信息卡片 + "去下单"按钮 |
| 场景C：默认启动 | 品牌Logo + 加载动画 → 自动跳转 |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| scene | string | URL参数/扫码参数 | 场景值：activity/share/default |
| activityId | string | URL参数 | 活动ID |
| merchantId | string | URL参数 | 商家ID（分享场景） |
| productId | string | URL参数 | 商品ID（分享场景） |
| channel | string | URL参数 | 来源渠道（用于统计） |
| inviteCode | string | URL参数 | 邀请码（拉新场景） |
| targetPath | string | 解析结果 | 目标跳转路径 |

### 用户操作与交互逻辑

1. 页面 `onLoad` 解析URL参数中的 `scene` 字段
2. 检查登录态：
   - 已登录 → 继续流程
   - 未登录 → 跳转WX-02授权页（授权后回到本页继续）
3. 根据scene分发：
   - `scene=activity` → 调用活动详情接口，展示活动页面，点击按钮跳转小程序活动页
   - `scene=share` → 展示分享的商家/商品信息，点击按钮跳转小程序商家详情/商品详情
   - `scene=default` 或无参数 → 自动跳转WX-03快捷入口页
4. 记录渠道来源（调用埋点接口）

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 活动详情 | GET | /api/activity/:id | 无 |
| 分享内容详情 | GET | /api/share/detail | `{ type, targetId }` |
| 渠道来源记录 | POST | /api/analytics/channel | `{ channel, scene, userId? }` |

### 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 活动已过期 | 展示"活动已结束" + 引导去首页 |
| 参数解析失败 | 跳转WX-03默认入口 |
| 分享商家不存在 | 展示"商家已下架" + 引导去首页 |
| 跳转小程序失败 | Toast提示"请手动打开小程序" |
| 网络错误 | 提示"网络异常" + 重试按钮 |

### 验收要点

- [ ] 正常分享链接能正确解析参数
- [ ] 活动承接页正确展示活动信息
- [ ] 点击"立即参与"能跳转到小程序对应页面
- [ ] 分享商家信息正确展示
- [ ] 未登录时先跳转授权再回来
- [ ] 活动过期时正确展示提示
- [ ] 渠道来源统计正常记录

## WX-02 微信授权页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | WX-02 |
| 页面名称 | 微信授权页 |
| 路由 | pages/auth/index |
| 页面目标 | 完成微信授权登录和手机号绑定，建立用户登录态 |

### 入口与出口

- **入口**：WX-01启动页（未登录时自动跳转）、其他页面检测到未登录时
- **出口**：授权成功 → 返回来源页面或跳转WX-03

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 品牌Logo + 应用名称 |
| 中部 | 授权说明文案"为了给您提供更好的服务，需要获取以下信息" |
| 信息列表 | 获取项说明：昵称、头像、手机号 |
| 操作区 | "微信快捷登录"按钮（绑定getUserProfile） |
| 手机号步骤 | 获取微信用户信息后，展示"绑定手机号"按钮（button open-type="getPhoneNumber"） |
| 底部 | 用户协议和隐私政策链接 + 勾选同意 |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| step | number | 状态变量 | 当前步骤：1=微信授权，2=手机号绑定 |
| agreed | boolean | 用户操作 | 是否同意用户协议 |
| userInfo.openid | string | 微信API返回 | 用户OpenID |
| userInfo.unionid | string | 微信API返回 | 用户UnionID |
| userInfo.nickname | string | 微信API返回 | 昵称 |
| userInfo.avatar | string | 微信API返回 | 头像URL |
| phoneNumber | string | 微信API返回 | 手机号 |
| token | string | 服务端返回 | JWT Token |

### 用户操作与交互逻辑

1. **步骤1 - 微信授权：**
   - 用户勾选"同意协议"
   - 点击"微信快捷登录"按钮
   - 调用 `wx.login()` 获取code
   - 将code发送到后端换取openid和session_key
   - 调用 `wx.getUserProfile()` 获取用户昵称和头像
   - 进入步骤2

2. **步骤2 - 手机号绑定：**
   - 展示"绑定手机号"按钮（`<button open-type="getPhoneNumber">`）
   - 用户点击按钮授权手机号
   - 获取加密手机号数据发送到后端解密
   - 后端返回完整Token
   - 登录完成，保存Token，跳转目标页面

3. **跳过手机号（可选策略）：**
   - 如果配置允许，展示"跳过"按钮
   - 跳过后使用基础Token，部分功能受限（下单时再强制绑定手机号）

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 微信登录 | POST | /api/auth/wechat-login | `{ code: string, userInfo?: { nickname, avatar } }` |
| 绑定手机号 | POST | /api/auth/bindPhone | `{ encryptedData, iv, sessionKey }` |

### 校验规则

| 规则 | 说明 |
|------|------|
| 协议同意 | 必须勾选"同意用户协议"才可进行授权 |
| 微信版本 | getUserProfile需要微信版本 >= 2.10.4，低版本做降级 |

### 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 用户拒绝授权 | 展示"授权后才能使用完整功能" + 引导按钮 |
| 微信登录接口失败 | Toast"登录失败，请重试" + 重试按钮 |
| 手机号获取失败 | Toast"手机号获取失败" + 重试或手动输入 |
| 微信版本过低 | 提示"请升级微信后再使用" |

### 验收要点

- [ ] 用户协议勾选后才能点击登录按钮
- [ ] 微信授权流程正确（code换session → getUserProfile）
- [ ] 手机号绑定流程正确
- [ ] 授权完成后Token正确保存
- [ ] 拒绝授权时的引导提示正常
- [ ] 低版本微信降级提示正常

## WX-03 快捷入口页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | WX-03 |
| 页面名称 | 快捷入口页 |
| 路由 | pages/entry/index |
| 页面目标 | 展示附近服务、热门活动、快捷下单入口，引导用户进入小程序完成核心操作 |

### 入口与出口

- **入口**：WX-01启动页默认跳转、微信端TabBar首页
- **出口**：点击各入口 → 跳转小程序对应页面

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 当前定位城市 + 消息图标（红点） |
| 搜索栏 | 点击跳转小程序搜索页（占位，非真实输入） |
| Banner | 运营活动Banner（1-3张） |
| 服务入口 | 网格图标：商品下单、帮送、帮取、帮买、代办、更多 |
| 热门推荐 | 推荐商家列表（简化展示，3-5个） |
| 最近订单 | 最近一笔进行中订单（如有） |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| cityName | string | 定位 | 当前城市名称 |
| unreadCount | number | 服务端返回 | 未读消息数 |
| bannerList | array | 服务端返回 | Banner列表 `[{imageUrl, miniappPath}]` |
| serviceList | array | 服务端返回 | 服务入口列表 `[{name, icon, miniappPath}]` |
| recommendMerchants | array | 服务端返回 | 推荐商家（简化信息：名称、图片、距离、标签） |

| latestOrder.id | string | 服务端返回 | 订单ID |
| latestOrder.type | string | 服务端返回 | 订单类型 |
| latestOrder.statusText | string | 服务端返回 | 状态文案 |
| latestOrder.merchantName | string | 服务端返回 | 商家/服务名称 |

### 用户操作与交互逻辑

1. **搜索栏点击** → 跳转小程序搜索页 `navigateToMiniApp('pages/search/index')`
2. **Banner点击** → 跳转小程序对应路径
3. **服务入口点击**：
   - "商品下单" → `navigateToMiniApp('pages/home/index')`
   - "帮送" → `navigateToMiniApp('pages/errand/form?type=send')`
   - "帮取" → `navigateToMiniApp('pages/errand/form?type=fetch')`
   - "帮买" → `navigateToMiniApp('pages/errand/form?type=buy')`
   - "代办" → `navigateToMiniApp('pages/errand/form?type=errand')`
   - "更多" → `navigateToMiniApp('pages/category/index')`
4. **推荐商家点击** → 跳转小程序商家详情 `navigateToMiniApp('pages/merchant/detail?id=xxx')`
5. **最近订单点击** → 跳转小程序订单详情
6. **消息图标点击** → 跳转WX-05消息承接页

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 快捷入口数据 | GET | /api/wechat/home | `{ lat, lng }` |
| 最近订单 | GET | /api/order/latest | 无 |
| 未读消息数 | GET | /api/user/message/unread-count | 无 |

### 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 跳转小程序失败 | Toast"跳转失败，请手动搜索小程序" |
| 定位失败 | 使用默认城市，提示"请开启定位获取附近服务" |
| 数据加载失败 | 展示基本入口（本地配置），不依赖接口 |

### 验收要点

- [ ] Banner展示和跳转正常

- [ ] 最近订单卡片展示正常
- [ ] 定位城市正确显示
- [ ] 未读消息红点正确

## WX-06 客服与帮助页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | WX-06 |
| 页面名称 | 客服与帮助页 |
| 路由 | pages/help/index |
| 页面目标 | 提供客服说明、常见问题解答、联系方式，可接入微信客服能力 |

### 入口与出口

- **入口**：WX-03快捷入口页、WX-04订单查询页底部链接
- **出口**：在线客服 → 微信客服会话，更多帮助 → 跳转小程序客服中心

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 导航栏"帮助与客服" |
| 客服入口 | 在线客服按钮（微信客服）、客服电话按钮 |
| 常见问题 | FAQ分类列表（点击展开/折叠） |
| 底部 | "更多帮助" → 跳转小程序客服中心 |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| servicePhone | string | 配置 | 客服电话 |
| faqCategories | array | 服务端返回 | FAQ分类 `[{name, questions: [{q, a}]}]` |

### FAQ默认分类

| 分类 | 示例问题 |
|------|----------|
| 下单问题 | "如何下单？"、"起送价是什么？"、"如何修改订单？" |
| 配送问题 | "配送需要多久？"、"如何联系骑手？"、"配送范围是？" |
| 退款问题 | "如何申请退款？"、"退款多久到账？"、"部分退款怎么办？" |
| 跑腿问题 | "跑腿怎么收费？"、"帮买需要预付吗？"、"跑腿能取消吗？" |
| 账号问题 | "如何修改手机号？"、"如何注销账号？" |

### 用户操作与交互逻辑

1. **在线客服** → 使用 `<button open-type="contact">` 或 `wx.openCustomerServiceChat` 接入微信客服
2. **电话客服** → `wx.makePhoneCall({ phoneNumber: servicePhone })`
3. **FAQ点击** → 展开/折叠答案（手风琴）
4. **"更多帮助"** → `navigateToMiniApp('pages/service/index')`

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| FAQ列表 | GET | /api/service/faq | 无 |
| 客服配置 | GET | /api/service/config | 无 |
