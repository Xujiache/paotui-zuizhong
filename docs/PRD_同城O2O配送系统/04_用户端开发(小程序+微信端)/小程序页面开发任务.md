# 用户微信小程序页面开发任务

> 本文档包含用户微信小程序全部22个页面的详细开发规格。  
> 每个页面规格自包含，可独立交给开发者实现。

---

## 全局约定

### 统一响应格式

所有后端接口返回统一格式（与阶段03接口规范一致）：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

错误码规范：`0`成功，其余错误码按服务域分段定义（详见阶段03《接口规范与状态机》错误码表），如`11001`未登录，`11003`无权限，`10002`数据不存在，`10001`参数校验失败，`10005`服务器错误。

### 统一分页格式

列表类接口请求参数：`page`（页码，从1开始）、`pageSize`（每页数量，默认20）。

返回格式：

```json
{
  "list": [],
  "total": 0,
  "page": 1,
  "pageSize": 20
}
```

### 统一金额规范

- 后端所有金额字段以**分**为单位（整数），前端展示时转换为元（除以100，保留2位小数）
- 前端提交金额时也以**分**为单位

### 统一时间规范

- 后端返回时间戳（毫秒）或ISO 8601格式字符串
- 前端展示时使用 `utils/format.uts` 统一格式化

## MP-01 启动页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | MP-01 |
| 页面名称 | 启动页 |
| 路由 | pages/launch/index |
| 页面目标 | 应用启动时加载基础配置、获取定位、检查登录态，完成初始化后自动跳转至首页 |

### 入口与出口

- **入口**：用户打开小程序
- **出口**：自动跳转至 MP-02 首页；若未登录需要先完成微信授权再跳转

### 页面布局

| 区域 | 内容 |
|------|------|
| 全屏 | 品牌Logo居中 + 品牌名称 + 加载动画（lottie或CSS动画） |
| 底部 | 版本号文字，如"v1.0.0" |

### 关键组件

无自定义组件，纯页面逻辑。

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| loginStatus | boolean | 本地Storage读取 | 是否已登录 |
| token | string | 本地Storage读取 | JWT Token |
| cityCode | string | 定位API返回 | 当前城市编码 |
| latitude | number | 定位API返回 | 当前纬度 |
| longitude | number | 定位API返回 | 当前经度 |
| appConfig | object | 服务端返回 | 应用基础配置（版本、公告、开关等） |

### 用户操作与交互逻辑

1. 页面 `onLoad` 时并行执行：
   - 调用 `uni.getLocation` 获取用户定位
   - 从本地Storage读取Token，验证是否过期
   - 调用后端获取应用配置（首页Banner、活动等预加载数据）
2. 定位授权弹窗：
   - 用户允许 → 保存定位到Store
   - 用户拒绝 → 使用默认城市，进入首页后引导重新授权
3. 登录态检查：
   - Token有效 → 直接跳转首页
   - Token过期 → 调用 `wx.login` 获取code → 调用后端静默登录接口 → 获取新Token
   - 静默登录失败 → 标记未登录状态，进入首页后在需要时引导授权
4. 所有初始化完成后，自动跳转至首页（`uni.switchTab`）

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 微信静默登录 | POST | /api/auth/wechat-login | `{ code: string }` |
| 应用配置 | GET | /api/config/app | 无 |

### 校验规则

- 定位超时设置3秒，超时后使用默认城市
- Token校验包括格式检查和过期时间检查

### 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 定位授权被拒 | 使用默认城市，进入首页后顶部展示"点击开启定位"引导 |
| 网络不可用 | 展示"网络连接失败"提示，提供"重试"按钮 |
| 静默登录失败 | 标记未登录，正常进入首页，在下单等需要登录的操作时再引导 |
| 应用配置获取失败 | 使用本地缓存的上次配置，无缓存则使用默认配置 |

### 验收要点

- [ ] 首次打开触发定位授权弹窗
- [ ] 允许定位后能正确获取到城市信息
- [ ] 拒绝定位后能使用默认城市正常进入首页
- [ ] 已登录用户可直接进入首页
- [ ] 未登录用户可静默登录后进入首页
- [ ] 网络异常时展示重试按钮，重试后可正常加载
- [ ] 加载动画流畅，启动页展示时间不超过3秒

## MP-02 首页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | MP-02 |
| 页面名称 | 首页 |
| 路由 | pages/home/index |
| 页面目标 | 作为双主线统一入口，展示当前定位、Banner、商品分类、附近商家、跑腿入口和活动入口 |

### 入口与出口

- **入口**：MP-01启动页自动跳转、底部TabBar"首页"Tab
- **出口**：
  - 点击搜索栏 → MP-03搜索页
  - 点击分类图标 → MP-04分类频道页
  - 点击商家卡片 → MP-09商家详情页
  - 点击跑腿入口 → MP-15跑腿频道页
  - 点击Banner → 对应活动页或商家详情页
  - TabBar切换 → MP-19订单列表 / MP-22个人中心

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部导航栏 | 左侧：当前定位地址（可点击切换），右侧：消息图标（红点badge显示未读数） |
| 搜索栏 | 固定在导航栏下方，点击跳转到搜索页（非真实输入框） |
| Banner轮播 | 运营Banner，支持3-5张轮播，可配置跳转目标 |
| 分类导航 | 横向一排或两排图标，如：美食、生鲜、商超、鲜花、跑腿-帮送、跑腿-帮取、跑腿-帮买、全部分类 |
| 活动专区 | 可选区域，展示当前活动卡片（如新人券、满减活动） |
| 附近商家列表 | 纵向列表，展示附近商家卡片（商家图、名称、评分、月销、配送费、距离、起送价、营业状态） |
| 底部TabBar | 首页(当前) / 订单 / 个人中心 |

### 关键组件

| 组件 | 说明 |
|------|------|
| NavBar | 自定义导航栏，含定位地址和消息入口 |
| Swiper | Banner轮播 |
| CategoryGrid | 分类导航网格 |
| MerchantCard | 商家列表卡片 |
| TabBar | 底部Tab导航 |
| LoadMore | 滚动加载更多 |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| currentAddress | string | 定位/用户选择 | 当前定位地址文案 |
| unreadCount | number | 服务端返回 | 未读消息数量 |
| bannerList | array | 服务端返回 | Banner列表 `[{imageUrl, linkType, linkValue}]` |
| categoryList | array | 服务端返回 | 分类列表 `[{id, name, icon, type}]` |
| activityList | array | 服务端返回 | 活动列表 `[{id, title, imageUrl, linkType, linkValue}]` |
| merchantList | array | 服务端返回 | 商家列表 |
| merchantList[].id | string | 服务端返回 | 商家ID |
| merchantList[].name | string | 服务端返回 | 商家名称 |
| merchantList[].logo | string | 服务端返回 | 商家Logo URL |
| merchantList[].score | number | 服务端返回 | 评分（1-5，一位小数） |
| merchantList[].monthlySales | number | 服务端返回 | 月销量 |
| merchantList[].deliveryFee | number | 服务端返回 | 配送费（分） |
| merchantList[].minPrice | number | 服务端返回 | 起送价（分） |
| merchantList[].distance | number | 服务端返回 | 距离（米） |
| merchantList[].deliveryTime | string | 服务端返回 | 预计配送时间，如"约30分钟" |
| merchantList[].status | string | 服务端返回 | 营业状态：open/closed/rest |
| merchantList[].tags | array | 服务端返回 | 标签，如["满20减5","新店"] |

### 用户操作与交互逻辑

1. **下拉刷新**：触发下拉刷新，重新加载Banner、分类、商家列表
2. **上拉加载**：商家列表触底加载下一页
3. **定位地址点击**：弹出地址选择弹层，可选择已保存地址或重新定位
4. **消息图标点击**：跳转MP-06消息中心
5. **搜索栏点击**：跳转MP-03搜索页
6. **Banner点击**：根据linkType跳转（merchant→商家详情, activity→活动页, url→webview）
7. **分类图标点击**：跑腿类型→MP-15跑腿频道页，商品类目→MP-04分类频道页（携带类目ID）
8. **商家卡片点击**：跳转MP-09商家详情页（携带商家ID）
9. **休息中商家**：卡片置灰显示"休息中"，点击可查看但不可下单

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 首页数据 | GET | /api/home/data | `{ lat, lng, cityCode }` |
| 附近商家列表 | GET | /api/merchant/list | `{ lat, lng, page, pageSize, categoryId?, sort? }` |
| 未读消息数 | GET | /api/user/message/unread-count | 无 |

### 状态展示逻辑

| 商家状态 | 展示效果 |
|----------|----------|
| open(营业中) | 正常展示，可点击进入 |
| closed(已打烊) | 卡片置灰，标签显示"已打烊"，可查看不可下单 |
| rest(休息中) | 卡片置灰，标签显示"休息中"，可查看不可下单 |

### 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 网络错误 | 展示网络错误占位图 + "点击重试" |
| 商家列表为空 | 展示"附近暂无商家"空状态 + 引导切换地址 |
| 定位失效 | 顶部提示"定位失败，请手动选择地址" |
| Banner加载失败 | 隐藏Banner区域，不影响其他内容 |

### 验收要点

- [ ] 首页能正确展示当前定位地址
- [ ] Banner轮播正常，自动播放和手动滑动均可
- [ ] 分类导航展示完整，包含跑腿入口
- [ ] 商家列表正确展示距离、配送费、评分等信息
- [ ] 下拉刷新和上拉加载更多功能正常
- [ ] 点击商家卡片能正确跳转到商家详情
- [ ] 未读消息红点正确显示
- [ ] 休息中商家正确置灰展示

## MP-03 搜索页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | MP-03 |
| 页面名称 | 搜索页 |
| 路由 | pages/search/index |
| 页面目标 | 按商家名、商品名、服务词搜索，展示搜索结果列表 |

### 入口与出口

- **入口**：MP-02首页搜索栏点击
- **出口**：点击商家结果 → MP-09商家详情，点击返回 → 上一页

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 搜索输入框（自动聚焦） + 取消按钮 |
| 默认状态 | 历史搜索词（可清空）+ 热门搜索词 |
| 搜索结果 | 商家结果列表（复用MerchantCard组件） |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| keyword | string | 用户输入 | 搜索关键词 |
| historyList | array | 本地Storage | 搜索历史，最多保存20条 |
| hotList | array | 服务端返回 | 热门搜索词 |
| resultList | array | 服务端返回 | 搜索结果列表（商家+商品混合） |

### 用户操作与交互逻辑

1. 进入页面自动聚焦搜索框
2. 输入关键词后，300ms防抖触发搜索
3. 点击历史词或热词，填入搜索框并触发搜索
4. 搜索结果为空时展示"未找到相关结果"
5. 清空历史：点击"清空"按钮，弹出确认弹窗
6. 搜索成功后，将关键词存入本地搜索历史

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 搜索 | GET | /api/search | `{ keyword, lat, lng, page, pageSize }` |
| 热搜词 | GET | /api/search/hot | 无 |

### 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 搜索结果为空 | 展示空状态图 + "换个词试试" |
| 网络错误 | Toast提示"网络异常" |

### 验收要点

- [ ] 进入页面搜索框自动聚焦弹出键盘
- [ ] 输入关键词后300ms内触发搜索
- [ ] 搜索历史正常保存和展示（最多20条）
- [ ] 清空历史功能正常
- [ ] 热门搜索词展示正常
- [ ] 搜索结果列表展示正确
- [ ] 点击结果可跳转至商家详情
