# 骑手端APP页面开发任务清单

> 本文档包含骑手端APP全部18个页面的详细开发规格。  
> 技术栈：uni-app x (Vue3 + UTS)，编译目标：安卓+iOS双端APP。

---

## 全局约定

### 统一规范

- 接口响应格式：`{ code, message, data }`
- 金额以**分**为单位（整数），展示时转换为元
- 时间使用ISO 8601或毫秒时间戳
- 距离以**米**为单位，展示时自动转为"xx米"或"xx公里"

### 骑手端特殊约定

- 骑手端需持续后台定位上报（配送中状态）
- 新订单必须有语音播报+震动提醒
- 在线/离线状态切换影响订单池展示
- 扫码核验是取货的关键校验步骤
- 所有位置操作需检查定位权限

## RD-01 注册登录页

### 基本信息

| 属性 | 值 |
|------|-----|
| 页面编号 | RD-01 |
| 页面名称 | 注册登录页 |
| 路由 | pages/auth/login |
| 页面目标 | 骑手通过手机号+验证码完成注册/登录 |

### 入口与出口

- **入口**：APP启动（未登录时）
- **出口**：登录成功 → 已入驻跳转RD-05接单大厅，未入驻跳转RD-02，审核中跳转RD-03

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 品牌Logo + "骑手版" |
| 表单 | 手机号 + 验证码输入 |
| 操作 | "登录/注册"按钮 |
| 底部 | 用户协议 + 隐私政策 |

### 数据字段清单

| 字段名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| phone | string | 用户输入 | 手机号 |
| smsCode | string | 用户输入 | 验证码 |
| agreed | boolean | 用户操作 | 协议同意 |

### 依赖的后端接口

| 接口 | 方法 | 路径 | 关键参数 |
|------|------|------|----------|
| 发送验证码 | POST | /api/rider/auth/sms-code | `{ phone }` |
| 骑手登录 | POST | /api/rider/auth/login | `{ phone, smsCode }` |

### 校验规则

| 字段 | 规则 |
|------|------|
| 手机号 | `/^1[3-9]\d{9}$/` |
| 验证码 | 6位数字 |
| 协议 | 必须勾选 |

### 验收要点

- [ ] 验证码登录流程完整

### 用户操作与交互逻辑

1. **在线状态切换**：开关切换 → 更新状态 → 在线时展示订单池，离线时展示离线提示

4. **点击订单卡片** → 跳转RD-07订单详情（可查看完整信息）
5. **"抢单"按钮** → 弹出RD-08抢单确认页
6. **"更多筛选"** → 跳转RD-06筛选页
7. **新订单推送** → 语音播报+震动+列表自动刷新

| 在线 | 正常展示订单池+开关为绿色 |
| 离线 | 展示"您当前处于离线状态" + 开关为灰色 |
| 未审核 | 不可进入此页，跳转RD-03 |
