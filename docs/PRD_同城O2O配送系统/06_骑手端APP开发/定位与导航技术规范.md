## 一、持续定位方案

### 1.1 整体方案

骑手在配送过程中需持续上报位置，供用户追踪和平台监控。需要在APP前台、后台和锁屏状态下均能持续获取定位。

### 1.2 定位策略

| 状态 | 定位频率 | 精度要求 | 说明 |
|------|----------|----------|------|
| 待接单（在线） | 60秒/次 | 100米 | 低频上报，仅用于订单池匹配 |
| 已接单（前往取货） | 10秒/次 | 50米 | 中频上报，用户可追踪 |
| 配送中 | 5秒/次 | 20米 | 高频上报，用户实时追踪 |
| 离线 | 不上报 | - | 停止定位服务 |

### 1.3 安卓实现

```typescript
// services/locationService.uts

class LocationService {
  private watchId: number | null = null;
  private uploadInterval: ReturnType<typeof setInterval> | null = null;
  private currentFrequency: number = 10000; // 默认10秒
  private locationBuffer: LocationPoint[] = [];

  // 启动持续定位
  async startTracking(frequency: number): Promise<void> {
    this.currentFrequency = frequency;

    // #ifdef APP-PLUS
    const platform = uni.getSystemInfoSync().platform;

    if (platform === 'android') {
      await this.startAndroidTracking();
    } else {
      await this.startIOSTracking();
    }
    // #endif

    // 启动定时上报
    this.startUploadTimer();
  }

  // 安卓持续定位
  private async startAndroidTracking(): Promise<void> {
    // 方案1: 原生插件 - 前台Service + FusedLocationProvider
    const locationPlugin = uni.requireNativePlugin('AMap-Location');

    locationPlugin.startLocation({
      accuracy: 'high',           // 高精度
      interval: this.currentFrequency,
      distanceFilter: 10,         // 最小距离变化（米）
      needAddress: false,         // 不需要地址解析（减少资源消耗）
      isMockEnable: false,        // 禁止模拟定位
    }, (result: LocationResult) => {
      if (result.code === 0) {
        this.onLocationUpdate({
          latitude: result.latitude,
          longitude: result.longitude,
          accuracy: result.accuracy,
          speed: result.speed,
          bearing: result.bearing,
          timestamp: Date.now(),
        });
      }
    });

    // 启动前台Service（保证后台定位不被杀死）
    const keepAlive = uni.requireNativePlugin('Keep-Alive');
    keepAlive.startForegroundService({
      title: '骑手版',
      content: '正在配送中...',
      icon: 'notification_icon',
    });
  }

  // iOS持续定位
  private async startIOSTracking(): Promise<void> {
    const locationPlugin = uni.requireNativePlugin('AMap-Location');

    locationPlugin.startLocation({
      accuracy: 'kCLLocationAccuracyBest',
      distanceFilter: 10,
      allowsBackgroundLocationUpdates: true, // 允许后台定位
      pausesLocationUpdatesAutomatically: false, // 不自动暂停
    }, (result: LocationResult) => {
      if (result.code === 0) {
        this.onLocationUpdate({
          latitude: result.latitude,
          longitude: result.longitude,
          accuracy: result.accuracy,
          speed: result.speed,
          bearing: result.bearing,
          timestamp: Date.now(),
        });
      }
    });
  }

  // 定位更新回调
  private onLocationUpdate(point: LocationPoint): void {
    // 过滤异常定位（精度大于200米的丢弃）
    if (point.accuracy > 200) return;

    // 过滤漂移（与上一点距离过远的丢弃）
    if (this.locationBuffer.length > 0) {
      const last = this.locationBuffer[this.locationBuffer.length - 1];
      const distance = this.calculateDistance(last, point);
      if (distance > 5000) return; // 5秒内移动超过5km，判定为漂移
    }

    this.locationBuffer.push(point);

    // 更新Store中的当前位置
    const locationStore = useLocationStore();
    locationStore.updateLocation(point);
  }

  // 启动定时上报
  private startUploadTimer(): void {
    this.uploadInterval = setInterval(() => {
      this.uploadLocations();
    }, this.currentFrequency);
  }

  // 上报位置到服务端
  private async uploadLocations(): Promise<void> {
    if (this.locationBuffer.length === 0) return;

    const points = [...this.locationBuffer];
    this.locationBuffer = [];

    try {
      await api.post('/api/rider/location/report', {
        points: points.map(p => ({
          lat: p.latitude,
          lng: p.longitude,
          accuracy: p.accuracy,
          speed: p.speed,
          bearing: p.bearing,
          timestamp: p.timestamp,
        })),
      });
    } catch (e) {
      // 上报失败，放回缓冲区（断网缓存）
      this.locationBuffer.unshift(...points);
      // 如果缓冲区过大，写入本地数据库
      if (this.locationBuffer.length > 100) {
        await this.saveToLocal(this.locationBuffer.splice(0, 50));
      }
    }
  }

  // 动态调整定位频率
  updateFrequency(frequency: number): void {
    this.currentFrequency = frequency;
    if (this.uploadInterval) {
      clearInterval(this.uploadInterval);
      this.startUploadTimer();
    }
  }

  // 停止定位
  stopTracking(): void {
    const locationPlugin = uni.requireNativePlugin('AMap-Location');
    locationPlugin.stopLocation();

    if (this.uploadInterval) {
      clearInterval(this.uploadInterval);
      this.uploadInterval = null;
    }

    // 停止前台Service
    const keepAlive = uni.requireNativePlugin('Keep-Alive');
    keepAlive.stopForegroundService();

    // 上报剩余缓冲区
    this.uploadLocations();
  }

  // 距离计算（Haversine公式）
  private calculateDistance(p1: LocationPoint, p2: LocationPoint): number {
    const R = 6371000;
    const dLat = (p2.latitude - p1.latitude) * Math.PI / 180;
    const dLng = (p2.longitude - p1.longitude) * Math.PI / 180;
    const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
      Math.cos(p1.latitude * Math.PI / 180) * Math.cos(p2.latitude * Math.PI / 180) *
      Math.sin(dLng/2) * Math.sin(dLng/2);
    return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  }

  // 断网时保存到本地SQLite
  private async saveToLocal(points: LocationPoint[]): Promise<void> {
    // SQLite存储实现
  }
}

interface LocationPoint {
  latitude: number;
  longitude: number;
  accuracy: number;
  speed: number;
  bearing: number;
  timestamp: number;
}
```

### 1.5 电量优化

| 优化措施 | 说明 |
|----------|------|
| 动态频率 | 根据配送状态调整定位频率 |
| 距离过滤 | 移动距离 < 10米时不触发回调 |
| 精度降级 | WiFi环境下可降低GPS精度 |
| 批量上报 | 缓冲多个点后批量上报，减少网络请求 |
| 停止待机 | 离线状态完全停止定位 |

## 二、轨迹上报方案

### 2.1 数据格式

```typescript
interface TrackReport {
  orderId: string;
  riderId: string;
  points: TrackPoint[];
}

interface TrackPoint {
  lat: number;       // 纬度
  lng: number;       // 经度
  accuracy: number;  // 精度（米）
  speed: number;     // 速度（m/s）
  bearing: number;   // 方向角（度）
  timestamp: number; // 时间戳（毫秒）
}
```

### 2.2 上报策略

| 策略 | 说明 |
|------|------|
| 实时上报 | 每个定位周期结束后立即上报 |
| 批量上报 | 累积5个点后批量上报（备选方案） |
| 断网缓存 | 断网时存入本地SQLite，恢复后批量上报 |
| 去重过滤 | 相同坐标（误差 < 5米）且间隔 < 3秒的点去重 |
| 数据压缩 | 上报前对轨迹数据做精度压缩（保留6位小数） |

### 2.3 断网缓存与恢复

```typescript
// services/trackService.uts

class TrackService {
  private db: any;

  // 断网时保存轨迹到SQLite
  async cacheTrackPoints(orderId: string, points: TrackPoint[]): Promise<void> {
    for (const point of points) {
      await this.execSQL(
        `INSERT INTO track_cache (order_id, lat, lng, accuracy, speed, bearing, timestamp, synced)
         VALUES (?, ?, ?, ?, ?, ?, ?, 0)`,
        [orderId, point.lat, point.lng, point.accuracy, point.speed, point.bearing, point.timestamp]
      );
    }
  }

  // 网络恢复后批量上报
  async syncCachedTracks(): Promise<void> {
    const cached = await this.selectSQL(
      'SELECT * FROM track_cache WHERE synced = 0 ORDER BY timestamp ASC LIMIT 200'
    );

    if (cached.length === 0) return;

    // 按订单分组
    const grouped: Record<string, TrackPoint[]> = {};
    cached.forEach((row: any) => {
      if (!grouped[row.order_id]) grouped[row.order_id] = [];
      grouped[row.order_id].push({
        lat: row.lat,
        lng: row.lng,
        accuracy: row.accuracy,
        speed: row.speed,
        bearing: row.bearing,
        timestamp: row.timestamp,
      });
    });

    // 逐订单批量上报
    for (const [orderId, points] of Object.entries(grouped)) {
      try {
        await api.post('/api/rider/location/batch-report', { orderId, points });
        // 标记为已同步
        const ids = cached.filter((r: any) => r.order_id === orderId).map((r: any) => r.id);
        await this.execSQL(
          `UPDATE track_cache SET synced = 1 WHERE id IN (${ids.join(',')})`
        );
      } catch (e) {
        break; // 上报失败，停止后续上报
      }
    }
  }

  // 清理已同步的旧数据（保留最近24小时）
  async cleanOldData(): Promise<void> {
    const cutoff = Date.now() - 24 * 60 * 60 * 1000;
    await this.execSQL('DELETE FROM track_cache WHERE synced = 1 AND timestamp < ?', [cutoff]);
  }
}
```

### 3.3 路线规划

```typescript
// services/mapService.uts

class MapService {
  // 路线规划（骑行）
  async planRoute(
    start: { lat: number; lng: number },
    end: { lat: number; lng: number }
  ): Promise<RouteResult> {
    return new Promise((resolve, reject) => {
      const amap = uni.requireNativePlugin('AMap-Route');
      amap.calculateRidingRoute({
        startPoint: { latitude: start.lat, longitude: start.lng },
        endPoint: { latitude: end.lat, longitude: end.lng },
      }, (result: any) => {
        if (result.code === 0) {
          resolve({
            distance: result.distance,    // 距离（米）
            duration: result.duration,     // 预计时间（秒）
            polyline: result.polyline,     // 路线折线点
          });
        } else {
          reject(new Error('路线规划失败'));
        }
      });
    });
  }

  // 调起外部导航
  startNavigation(
    destination: { lat: number; lng: number; name: string }
  ): void {
    const platform = uni.getSystemInfoSync().platform;

    if (platform === 'android') {
      // 优先调起高德地图，其次百度地图
      this.navigateAndroid(destination);
    } else {
      // iOS优先苹果地图，其次高德
      this.navigateIOS(destination);
    }
  }

  private navigateAndroid(dest: { lat: number; lng: number; name: string }): void {
    // 尝试调起高德地图
    const amapUrl = `amapuri://route/plan/?dlat=${dest.lat}&dlon=${dest.lng}&dname=${encodeURIComponent(dest.name)}&dev=0&t=2`;

    plus.runtime.openURL(amapUrl, (err: any) => {
      // 高德未安装，尝试百度
      const bdUrl = `baidumap://map/direction?destination=name:${encodeURIComponent(dest.name)}|latlng:${dest.lat},${dest.lng}&mode=riding`;
      plus.runtime.openURL(bdUrl, () => {
        // 都未安装，使用H5地图
        const webUrl = `https://uri.amap.com/navigation?to=${dest.lng},${dest.lat},${encodeURIComponent(dest.name)}&mode=ride`;
        plus.runtime.openURL(webUrl);
      });
    });
  }

  private navigateIOS(dest: { lat: number; lng: number; name: string }): void {
    // 弹出选择框
    uni.showActionSheet({
      itemList: ['苹果地图', '高德地图'],
      success: (res) => {
        if (res.tapIndex === 0) {
          const url = `http://maps.apple.com/?daddr=${dest.lat},${dest.lng}&dirflg=w`;
          plus.runtime.openURL(url);
        } else {
          const url = `iosamap://path?dlat=${dest.lat}&dlon=${dest.lng}&dname=${encodeURIComponent(dest.name)}&dev=0&t=2`;
          plus.runtime.openURL(url);
        }
      }
    });
  }
}

interface RouteResult {
  distance: number;
  duration: number;
  polyline: Array<{ lat: number; lng: number }>;
}
```

## 四、扫码核验方案

### 4.1 整体方案

骑手到店取货时，扫描商家出示的取货码（二维码/条形码），核验成功后确认取货。

### 4.2 技术实现

```typescript
// services/scanService.uts

class ScanService {
  // 调起扫码
  async scan(): Promise<string> {
    return new Promise((resolve, reject) => {
      uni.scanCode({
        scanType: ['qrCode', 'barCode'],
        onlyFromCamera: true, // 仅允许相机扫码，不允许从相册选择
        success: (res) => {
          resolve(res.result);
        },
        fail: (err) => {
          if (err.errMsg.includes('cancel')) {
            reject(new Error('用户取消扫码'));
          } else {
            reject(new Error('扫码失败'));
          }
        }
      });
    });
  }

  // 扫码核验取货
  async verifyPickupCode(orderId: string): Promise<boolean> {
    try {
      const code = await this.scan();

      // 调用后端核验接口
      const result = await api.post(`/api/rider/order/${orderId}/verify`, { code });

      if (result.data.verified) {
        uni.showToast({ title: '核验成功', icon: 'success' });
        return true;
      } else {
        uni.showToast({ title: '取货码不匹配', icon: 'none' });
        return false;
      }
    } catch (e: any) {
      if (e.message === '用户取消扫码') {
        return false;
      }
      uni.showToast({ title: '扫码失败，请手动输入', icon: 'none' });
      return false;
    }
  }
}
```

## 五、锁屏语音播报方案

### 5.1 整体方案

新订单到达时，无论APP处于前台、后台还是锁屏状态，均需语音播报提醒骑手。

### 5.2 实现方式

```typescript
// services/voiceService.uts

class VoiceService {
  private enabled: boolean = true;
  private playCount: number = 0;
  private maxCount: number = 3;

  // 新订单语音播报
  playNewOrderAlert(orderInfo: { type: string; fee: number }): void {
    if (!this.enabled) return;

    const typeText = {
      product: '外卖',
      send: '帮送',
      fetch: '帮取',
      buy: '帮买',
      errand: '代办',
    }[orderInfo.type] || '配送';

    const feeText = (orderInfo.fee / 100).toFixed(1);
    const text = `您有新的${typeText}订单，配送费${feeText}元，请及时接单`;

    this.speak(text);
  }

  private speak(text: string): void {
    this.playCount = 0;
    this.doSpeak(text);
  }

  private doSpeak(text: string): void {
    if (this.playCount >= this.maxCount) {
      this.playCount = 0;
      return;
    }

    // #ifdef APP-PLUS
    const tts = uni.requireNativePlugin('TTS-Engine');
    tts.speak({
      text,
      language: 'zh-CN',
      rate: uni.getSystemInfoSync().platform === 'ios' ? 0.5 : 1.0,
      volume: 1.0,
      onDone: () => {
        this.playCount++;
        if (this.playCount < this.maxCount) {
          setTimeout(() => this.doSpeak(text), 1500);
        }
      },
      onError: () => {
        // TTS失败，使用预录音频作为降级
        this.playFallbackAudio();
      }
    });
    // #endif

    // 同时触发震动
    uni.vibrateShort({});
  }

  // 降级方案：播放预录制音频
  private playFallbackAudio(): void {
    const audio = uni.createInnerAudioContext();
    audio.src = '/static/audio/new_order.mp3';
    audio.play();
  }

  setEnabled(enabled: boolean): void {
    this.enabled = enabled;
  }

  stop(): void {
    this.playCount = this.maxCount; // 停止循环
    const tts = uni.requireNativePlugin('TTS-Engine');
    tts.stop();
  }
}
```

### 5.3 安卓与iOS差异

| 差异点 | 安卓 | iOS |
|--------|------|-----|
| 后台播报 | 通过前台Service保活实现 | 需Background Audio模式 |
| 锁屏播报 | 前台Service中直接调用TTS | 通过推送通知+自定义声音 |

| TTS质量 | 依赖系统TTS引擎 | AVSpeechSynthesizer质量较高 |

```typescript
      title: '保证订单及时接收',
      content: message,
      confirmText: '去设置',
      success: (res) => {
        if (res.confirm) {
          // 打开APP设置页面
          const keepAlive = uni.requireNativePlugin('Keep-Alive');
          keepAlive.openAppSettings();
        }
      }
    });
  }
}
```

### 6.2 iOS保活

```
iOS保活策略组合：

1. Background Location (主方案)
   - 开启后台定位模式
   - 配送中持续获取位置
   - 系统不会轻易杀死正在使用定位的APP

2. Remote Notifications (推送唤醒)
   - APNs推送可在APP被杀死后送达
   - 静默推送(content-available)可唤醒APP执行短时后台任务

3. Background Fetch (定期刷新)
   - 系统定期唤醒APP执行后台刷新
   - 频率由系统决定，不可精确控制

Info.plist配置:
UIBackgroundModes:
  - location
  - remote-notification
  - fetch
  - audio
```

## 七、安卓与iOS平台差异总结

| 能力 | 安卓方案 | iOS方案 | 差异处理 |
|------|----------|---------|----------|
| 持续定位 | 前台Service + FusedLocation | Background Location | 封装统一接口 |
| 后台保活 | 前台Service + 厂商适配 | Background Modes组合 | 平台判断分支 |
| 导航调起 | 高德→百度→H5 | 苹果→高德(ActionSheet选择) | 平台判断分支 |
| 扫码 | uni.scanCode(统一) | uni.scanCode(统一) | 无差异 |
| 语音播报 | Android TTS | AVSpeechSynthesizer | 封装统一接口 |
| 推送 | 极光(FCM+厂商通道) | APNs | 极光SDK统一封装 |
| 定位权限 | 动态申请+后台定位权限 | Info.plist声明+使用时弹窗 | 各自处理 |
| 电池优化 | 需处理厂商限制 | 系统统一管理 | 安卓需厂商引导 |
